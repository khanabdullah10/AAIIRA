# AAIIRA MARBLES — Luxury Fine Architectural Stone Atelier

> *Living Heritage & Geological Mastery Since 2008*

AAIIRA Marbles is the premier direct curator, fabricator, and exclusive distributor of the world’s rarest quarried natural stone series. Sourced directly from historical Italian and Mediterranean strata—from the Apuan Alps in Carrara to Brescia and Verona—AAIIRA provides bookmatched slabs, monolithic architectural envelopes, floating staircases, and bespoke interior commissions for prestigious architects, designers, and private residences globally.

- **Kinetic Monolithic Typography & 3D WebGL Monolith**:
  - Precision GSAP vector intro animation and reactive viewport framing.
  - Interactive Three.js WebGL stone monolith that floats, fractures, and settles into the contact colophon upon scroll.
  - Interactive hover flashlight/torch inspection system with sub-pixel raycasting.

- **Stone & Style Curated Brands Showcase (`/brands`)**:
  - Full digital recreation of the prestigious Stone & Style architectural showroom aesthetic.

## Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics & WebGL**: [Three.js](https://threejs.org/) (Custom shaders, PBR physical materials, Draco GLTF loader)
- **Smooth Momentum Scrolling**: [Lenis](https://lenis.darkroom.engineering/) (165Hz fluid momentum engine)
- **Kinetic Animations**: [GSAP 3](https://greensock.com/gsap/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

### Prerequisites

- Node.js 18.18+ (Node 20+ recommended)
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/khanabdullah10/AAIIRA.git
cd AAIIRA

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the Atelier.

### Production Build

```bash
# Compile optimized static production build
npm run build

# Start production server
npm run start
```
